# DPS++

A Pathogenic mod that provides realtime DPS, and replaces vanilla DPS numbers with accurately calculated values, accounting for infusors, mitochondria, mutations, and plasmids.

> **Vibe-Coded Software Ahead**

## Features

- **Accurate tooltip DPS** — replaces the vanilla weapon DPS in tooltips with exact values that account for all combat modifiers
- **Per-infusor contributions** — shows each infusor's DPS impact inline (e.g. `Triosome **(+43 DPS)**`)
- **Charged DPS** — displays overcharged DPS deltas
- **Before/after preview** — shows DPS comparison when combining or upgrading organelles
- **Editor stats** — shows total base and charged DPS in the editor's vitals area (top left)
- **Slot preview** — previews DPS with projected infusor connections when hovering a weapon over a slot
- **Realtime combat DPS** — rolling DPS meter during combat, displayed next to the cores counter
